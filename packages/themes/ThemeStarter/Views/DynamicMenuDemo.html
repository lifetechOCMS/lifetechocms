Dynamic navigation demonstration

This advanced example uses DynamicMenuLayout.html and DynamicHeader.html. The header requests navigation from the LifeTechOCMS backend instead of defining its menu links in HTML.

How it works

  1. The browser requests /menus/is-navigation.
  2. The backend identifies the visitor through the existing session.
  3. The API returns navigation permitted for the visitor’s roles.
  4. The renderer builds links and nested lists from the returned data.

What to observe

  • Compare the navigation while signed out and signed in.
  • Check parent and child links and links configured for a new tab.
  • Review the loading, empty-result and failed-request messages.
  • Menu visibility does not replace page or API authorization.

If this page still shows the static Home, About and Contact navigation, assign it to DynamicMenuLayout.html in the backend. Default.html remains the automatic layout until that custom assignment is made.
