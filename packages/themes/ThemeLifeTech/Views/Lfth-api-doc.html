Getting Started

LifeTech provides a comprehensive RESTful API that allows you to interact with your content programmatically. Build custom integrations, mobile apps, or automate content management tasks.

Base URL

https://api.lifetech.com/v1

Key Features

  • RESTful API with JSON responses
  • OAuth 2.0 authentication
  • Rate limiting and throttling
  • Comprehensive error handling
  • Interactive API explorer

Authentication

All API requests require authentication using OAuth 2.0. You'll need to obtain an access token before making requests.

POST /oauth/token
Content-Type: application/json

{
  "grant_type": "client_credentials",
  "client_id": "your_client_id",
  "client_secret": "your_client_secret"
}

Response

{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "Bearer",
  "expires_in": 3600
}

API Endpoints

Posts

GET /posts

Retrieve all posts with pagination support.

Query Parameters:

  • page - Page number (default: 1)
  • per_page - Items per page (default: 20, max: 100)
  • status - Filter by status (published, draft, archived)

Sample Request:

GET https://api.lifetech.com/v1/posts?page=1&per_page=20&status=published

Sample Response:

{
  "data": [
    {
      "id": 1,
      "title": "Welcome to LifeTech",
      "content": "This is the content...",
      "status": "published",
      "created_at": "2024-01-15T10:30:00Z",
      "updated_at": "2024-01-15T10:30:00Z"
    }
  ],
  "meta": {
    "current_page": 1,
    "per_page": 20,
    "total": 100
  }
}

Code Examples:

JavaScript (Fetch)

fetch('https://api.lifetech.com/v1/posts?page=1&per_page=20', {
  headers: {
    'Authorization': 'Bearer YOUR_ACCESS_TOKEN',
    'Content-Type': 'application/json'
  }
})
.then(res => res.json())
.then(data => console.log(data));

Python (Requests)

import requests

headers = {
    'Authorization': 'Bearer YOUR_ACCESS_TOKEN',
    'Content-Type': 'application/json'
}

response = requests.get(
    'https://api.lifetech.com/v1/posts',
    params={'page': 1, 'per_page': 20},
    headers=headers
)
print(response.json())

cURL

curl -X GET "https://api.lifetech.com/v1/posts?page=1&per_page=20" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json"
POST /posts

Create a new post.

Request Body:

{
  "title": "My New Post",
  "content": "Post content here...",
  "status": "published",
  "categories": [1, 2],
  "tags": ["web", "development"]
}

Sample Response:

{
  "data": {
    "id": 123,
    "title": "My New Post",
    "content": "Post content here...",
    "status": "published",
    "created_at": "2024-01-15T10:30:00Z",
    "updated_at": "2024-01-15T10:30:00Z"
  }
}

Code Examples:

JavaScript (Fetch)

fetch('https://api.lifetech.com/v1/posts', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_ACCESS_TOKEN',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    title: 'My New Post',
    content: 'Post content here...',
    status: 'published',
    categories: [1, 2]
  })
})
.then(res => res.json())
.then(data => console.log(data));

Python (Requests)

import requests

headers = {
    'Authorization': 'Bearer YOUR_ACCESS_TOKEN',
    'Content-Type': 'application/json'
}

data = {
    'title': 'My New Post',
    'content': 'Post content here...',
    'status': 'published',
    'categories': [1, 2]
}

response = requests.post(
    'https://api.lifetech.com/v1/posts',
    json=data,
    headers=headers
)
print(response.json())

cURL

curl -X POST "https://api.lifetech.com/v1/posts" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "My New Post",
    "content": "Post content here...",
    "status": "published",
    "categories": [1, 2]
  }'

Media

POST /media/upload

Upload media files (images, videos, documents).

Request (Form Data):

Content-Type: multipart/form-data

file: [binary file data]
title: "My Image"
description: "Image description"

Sample Response:

{
  "data": {
    "id": 456,
    "filename": "image.jpg",
    "url": "https://cdn.lifetech.com/media/image.jpg",
    "size": 1024000,
    "mime_type": "image/jpeg",
    "created_at": "2024-01-15T10:30:00Z"
  }
}

Code Examples:

JavaScript

const formData = new FormData();
formData.append('file', fileInput.files[0]);
formData.append('title', 'My Image');

fetch('https://api.lifetech.com/v1/media/upload', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_ACCESS_TOKEN'
  },
  body: formData
})
.then(res => res.json())
.then(data => console.log(data));

Python

files = {'file': open('image.jpg', 'rb')}
data = {'title': 'My Image'}

response = requests.post(
    'https://api.lifetech.com/v1/media/upload',
    files=files,
    data=data,
    headers={'Authorization': 'Bearer YOUR_ACCESS_TOKEN'}
)
print(response.json())

Rate Limiting

API requests are rate-limited to ensure fair usage and system stability.

Rate Limit: 1000 requests per hour per API key

Rate limit headers are included in all responses:

  • X-RateLimit-Limit - Total requests allowed
  • X-RateLimit-Remaining - Requests remaining
  • X-RateLimit-Reset - Time when limit resets
